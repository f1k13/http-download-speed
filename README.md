# speedtest

Замер скорости скачивания с заданного адреса.

Консольная утилита делает **10 последовательных запросов** к URL, на каждом дожидается
полного получения тела ответа и выводит:

- время, объём и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость скачивания.

Стек: TypeScript (strict, ESM, `import`), встроенные модули Node.js — runtime-зависимостей нет.

## Запуск через Docker Compose (рекомендуется)

Нужен только Docker. Из корня проекта:

```bash
# URL аргументом
docker compose run --rm speedtest https://proof.ovh.net/files/10Mb.dat

# или через переменную окружения
URL=https://proof.ovh.net/files/10Mb.dat docker compose run --rm speedtest

# без URL — используется тестовый файл по умолчанию (10 МБ с OVH)
docker compose run --rm speedtest
```

Первый запуск сам соберёт образ. После изменения кода пересобрать: `docker compose build`.

## Запуск через Docker без Compose

```bash
docker build -t speedtest .
docker run --rm speedtest https://proof.ovh.net/files/10Mb.dat
```

## Структура

```
src/
  index.ts      CLI: аргументы, цикл из 10 запросов, вывод
  download.ts   один HTTP(S)-запрос с полным чтением тела, редиректы, таймаут
  stats.ts      расчёт итогов и форматирование
Dockerfile      multi-stage: сборка TS → лёгкий runtime-образ только с dist/
docker-compose.yml
```

Пример вывода:

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 10 (последовательно)

# 1    10.49 MB     5914.3 ms     14.18 Mbit/s
# 2    10.49 MB     4118.4 ms     20.37 Mbit/s
...
#10    10.49 MB    19149.1 ms      4.38 Mbit/s

--- Итого ---
Успешных запросов:     10 из 10
Среднее время запроса: 6383.7 ms
```

> User-Agent — для замера лучше брать тестовые файлы, например `https://proof.ovh.net/files/10Mb.dat`.

## Единицы измерения

| Величина | Единица | Пояснение |
|---|---|---|
| Время запроса | **мс** (миллисекунды) | от отправки запроса до получения последнего байта тела |
| Объём | **B / KB / MB / GB** | десятичные: 1 KB = 1000 байт, 1 MB = 1 000 000 байт; в итоге также печатается точное число байт |
| Скорость | **Mbit/s** (мегабиты в секунду, 1 Mbit = 10⁶ бит) | основная единица — в ней же указывают тарифы провайдеров и спидтесты; в скобках дублируется в **MB/s** (мегабайты в секунду) |

Итоговая скорость считается как `общий объём / суммарное время всех успешных запросов`
(а не как среднее скоростей отдельных запросов), поэтому корректно учитывает разные размеры ответов.

## Детали замера

- Каждый запрос открывает **новое соединение** (без keep-alive), чтобы все 10 замеров
  были в одинаковых условиях: DNS + TCP + TLS + скачивание.
- Отправляется `Accept-Encoding: identity` — считаются реальные байты ресурса, без gzip-сжатия.
- Отправляется `Cache-Control: no-cache`, чтобы промежуточные кеши по возможности отдавали свежий ответ.
- Редиректы (3xx) отслеживаются автоматически (до 5), их время входит во время запроса.
- Таймаут неактивности — 60 секунд. Неуспешные запросы (ошибка сети, не-2xx) выводятся,
  но не участвуют в расчёте итогов.
